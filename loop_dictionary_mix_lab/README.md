# Python Loops and Dictionaries Lab

This repository contains my solutions to Python Programming Lab exercises, covering loops, dictionaries, and mixed programming problems.

## Repository Structure

The repository is organized into three main folders:

### 📁 For Loop

Contains Python programs that use **for loops** to solve a variety of problems, including:

* Number, square, and cube tables
* Sum and average calculations
* Factorial calculation
* Prime number checking
* Pattern printing
* Other for loop practice exercises

### 📁 While Loop

Contains Python programs that use **while loops** to solve different programming problems and strengthen understanding of iterative programming.

### 📁 Dictionary

Contains Python programs that demonstrate the use of **Python dictionaries**, including:

* Creating dictionaries
* Accessing and updating values
* Searching for keys
* Basic dictionary operations
* Mixed exercises combining loops and dictionaries

### 📁 Mixed Questions

Contains programming exercises that combine multiple concepts, such as:

* Loops with dictionaries
* Nested loops with dictionaries
* Conditional statements with loops
* Counters and accumulators
* Other integrated Python programming problems

## Concepts Practiced

* For loops
* While loops
* Nested loops
* Conditional statements (`if`, `else`)
* Accumulator and counter variables
* Pattern printing
* Prime numbers
* Factorials
* Dictionaries
* Combined loop and dictionary problems

## Technologies Used

* Python 3
* Visual Studio Code (VS Code)

## Purpose

The purpose of this repository is to practice fundamental Python programming concepts through laboratory exercises and problem-solving. The solutions focus on writing clear and efficient code using basic Python constructs without relying on advanced libraries.
